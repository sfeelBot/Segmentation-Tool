## 🚀 시작하기

### 필요 환경
- Python 3.12+ (Anaconda 권장)
- Windows 10/11 · macOS · Linux
- NVIDIA GPU 권장 (Maxwell 이상: GTX 9xx 이상, Quadro M4000/M5000 포함)
- RAM 16GB 이상 권장 (대형 이미지 50MB+ 처리 시 32GB 권장)

### 설치

```powershell
# 1) 가상환경 만들기
py -3.12 -m venv .venv
.venv\Scripts\activate

# 2) PyTorch (GPU 맞는 빌드)
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128

# 3) 나머지 의존성
pip install -r requirements.txt

# 4) 실행
python main.py
```

GPU 별 추천 CUDA 빌드:

| GPU | 권장 빌드 |
|---|---|
| RTX 50 시리즈 (Blackwell) | `cu128` |
| RTX 40 / 30 / 20 | `cu124` / `cu121` |
| GTX 10 (Pascal) | `cu121` |
| Quadro M4000 / M5000 (Maxwell) | `cu118` |
| GPU 없음 | `cpu` |

## 🗂 프로젝트 시스템

### 앱 시작 시 — 프로젝트 선택 다이얼로그

앱을 실행하면 먼저 **프로젝트 선택 창** 이 뜹니다.

```
┌─────────────────────────────────────────┐
│  🎯 Segmentation Model UI               │
│  프로젝트를 선택하거나 새로 만들어 시작. │
│                                         │
│  [🎯  새 프로젝트]  [📂  프로젝트 열기] │
│                                         │
│  📋 최근 프로젝트                       │
│  ┌─────────────────────────────────────┐│
│  │ 🧠  PCB불량검사    2025-12-03 14:22 ││
│  │ 🧠  용접결함검사    2025-12-01 09:15 ││
│  └─────────────────────────────────────┘│
└─────────────────────────────────────────┘
```

- **🎯 새 프로젝트**: 이름 입력 → `projects/<이름>/` 폴더에 모든 데이터 격리해서 생성
- **📂 프로젝트 열기**: 기존 프로젝트 폴더 선택 (다른 경로의 폴더도 가능)
- **최근 프로젝트 목록**: 더블클릭으로 바로 열기

### 각 프로젝트가 자체적으로 갖는 것
- `images/` — 원본 이미지
- `annotations/` — JSON 어노테이션
- `checkpoints/` — 학습된 체크포인트
- `user_models/` — 커스텀 모델 코드 스냅샷
- `classes.json` — 클래스 정의
- `project.json` — 프로젝트 메타데이터

### 전역 공유
- `data/settings.json` — 언어·최근 프로젝트 목록
- `data/logs/` — 앱 전체 로그

> 💡 **이점**: 프로젝트별로 다른 클래스, 다른 체크포인트, 다른 이미지셋을 섞이지 않고 관리할 수 있음.

가장 많이 쓰는 탭입니다. 좌·중앙·우 세 패널로 구성:

```
┌────────────┬───────────────────────────────┬────────────┐
│ 🖼 이미지   │ 📐 🖌 🪣 🧹 🧲 🔲 ✋  브러시:[20] │ 📋 어노테이션 │
│ ┌────────┐ │ ↶ 🗑  ✅  ✨  🔳              │  목록       │
│ │● img1  │ │  ─────────────────────────── │ ┌────────┐ │
│ │● img2  │ │                              │ │#1 Mask…│ │
│ │○ img3  │ │        [캔버스 영역]         │ │#2 Mask…│ │
│ │✓ img4  │ │                              │ └────────┘ │
│ └────────┘ │                              │             │
│ ● 라벨링됨 │                              │ 📝 로그      │
│ ✓ OK      │                              │ ┌────────┐ │
│ ○ 미라벨   │                              │ │• 이미지…│ │
│ 🎨 클래스  │                              │ │⚠ GPU … │ │
│ ┌────────┐ │                              │ └────────┘ │
│ │class 1 │ │                              │            │
│ │class 2 │ │                              │            │
│ └────────┘ │                              │            │
└────────────┴───────────────────────────────┴────────────┘
```

### 🖼 좌측 패널 — 이미지 브라우저

```
┌─ 이미지 ─────── [파일] [폴더] [삭제] ┐
│ ●  frame_001.jpg                    │  ← 녹색 = 라벨링됨
│ ●  frame_002.jpg                    │
│ ○  frame_003.jpg                    │  ← 회색 = 미라벨
│ ✓  frame_004.jpg                    │  ← 파랑 = OK 표시 (명시적 검수 완료)
│ ●  frame_005.jpg                    │
└─────────────────────────────────────┘
● 라벨링됨  ✓ OK  ○ 미라벨
```

**버튼**
- **파일** — 개별 이미지 파일들 선택해서 추가
- **폴더** — 폴더 내 모든 이미지 일괄 추가 (백그라운드 스레드 + 진행바)
- **삭제** — 선택된 이미지 + 어노테이션 삭제

**다중 선택 & 삭제**
- Click / Shift+Click / Ctrl+Click 으로 여러 장 선택
- **Del** 키로 한 번에 삭제 (확인 팝업)

**이미지 이동 단축키**
- **↑ / Page Up** — 이전 이미지
- **↓ / Page Down** — 다음 이미지
- 캔버스에 포커스가 있어도 동작

### 🎨 좌측 하단 — 클래스 패널
```
┌─ 🎨 클래스 ───── [+] [-] [색변경] ┐
│  ■  background     (0)           │
│  ■  crack          (1) ← 선택됨   │
│  ■  defect         (2)           │
│  ■  scratch        (3)           │
└──────────────────────────────────┘
```
- 클릭으로 현재 클래스 선택 (다음에 그리는 어노테이션에 적용)
- 선택 도구로 어노테이션을 선택한 상태에서 클래스 클릭 → **선택된 어노테이션의 클래스를 일괄 변경**

### 🛠 툴바 — 이모지 아이콘 + 툴팁

| 아이콘 | 도구 | 단축키 | 설명 |
|---|---|---|---|
| 📐 | 폴리곤 | `P` | 꼭짓점 클릭 → 더블클릭으로 닫기 |
| 🖌 | 브러시 | `B` | 드래그로 픽셀 칠하기 |
| 🪣 | 윤곽 채우기 | `F` | 외곽선 그리면 내부 자동 채움 |
| 🧹 | 지우개 | `E` | 드래그한 픽셀만 제거 (폴리곤도 가능) |
| 🧲 | 연결 지우개 | — | 클릭 → 4-연결 같은 클래스 영역 전체 제거 |
| 🔲 | 선택 | `S` | 어노테이션 선택/이동/클래스 변경 |
| ✋ | 이동(Pan) | `H` | 캔버스 드래그로 이동 |
| — | 브러시 크기 | `[` `]` | 스핀박스로 직접 입력 가능 |
| ↶ | 실행취소 | `Ctrl+Z` | 최근 30단계까지 |
| 🗑 | 전체 삭제 | — | 현재 이미지의 모든 어노테이션 삭제 |
| ✅ | OK 표시 | — | 어노테이션 없어도 '검수 완료'로 마킹 (토글) |
| ✨ | 오토 라벨링 | — | [오토 라벨링 다이얼로그](#-오토-라벨링-워크플로우) |
| 🔳 | 이미지 크게 | `Tab` | 좌·우 패널 숨김/복원 |

> 💡 마우스 올리면 **도구 설명 + 단축키 + 사용법**이 툴팁으로 표시됩니다.

### 📐 폴리곤 도구 사용법
1. `P` 또는 📐 클릭
2. 꼭짓점 위치를 클릭으로 찍음 (커서에서 현재 꼭짓점까지 선이 미리보기로 그려짐)
3. **더블클릭** 또는 첫 꼭짓점 근처 클릭 → 폴리곤 닫기
4. `Esc` 로 취소

### 🖌 브러시 / 🪣 윤곽 채우기
- **브러시**: 일반적으로 드래그 = 칠
- **윤곽 채우기**: 영역의 외곽선을 그리면 닫혔을 때 자동으로 내부가 채워짐 (작은 틈은 자동 연결)
- 같은 클래스끼리 연결되면 자동으로 **하나의 어노테이션으로 병합**
- 픽셀 중복 자동 해소: 겹치는 위치에 다른 클래스 칠하면 새 쪽 우선

### 🧹 지우개 / 🧲 연결 지우개
- **🧹 픽셀 지우개**: 드래그한 범위의 픽셀만 삭제 (폴리곤도 자동으로 brush_mask 로 변환 후 삭제)
- **🧲 연결 지우개**: 클릭 한 번으로 해당 픽셀과 연결된 같은 클래스 영역 전체 삭제 (cv2.connectedComponents 사용)

### 🔲 선택 도구 심화 사용법
`S` 키로 선택 도구 활성화:

| 조작 | 결과 |
|---|---|
| 어노테이션 클릭 | 단일 선택 (기존 선택 교체) |
| **Shift + 클릭** | 선택에 추가/제거 (토글) |
| 빈 공간 드래그 | 노란 점선 사각형 → 내부 어노테이션 다중 선택 |
| **Shift + 드래그** | 기존 선택 유지하면서 추가 |
| 빈 공간 클릭 | 선택 해제 (Shift 없이) |
| **선택된 어노테이션 드래그** | 4방향 커서로 바뀌며 위치 이동 |
| 선택 후 **클래스 패널 클릭** | 선택된 항목들 클래스 일괄 변경 |
| 선택 후 **Del** | 선택된 항목들 삭제 |

### 🖱 마우스 / 뷰 조작
- **🖱 휠** — 줌인/아웃 (커서 위치 고정)
- **🖱 우클릭 드래그** — 캔버스 이동(패닝)
- **Space + 왼쪽 드래그** — 임시 패닝 (어떤 도구든)

### 🔑 N 키 — 이전 이미지 어노테이션 복사
이전에 라벨링한 이미지의 어노테이션을 현재 이미지에 **그대로 붙여넣기**.
- 연속된 비디오 프레임을 라벨링할 때 매우 유용
- 이미지 크기가 다르면 마스크 자동 resize (NEAREST)

### 📋 우측 패널 — 어노테이션 목록

```
┌─ 📋 어노테이션 목록 ───────────────┐
│ #1  [Mask] crack    @(140,220)  845px│
│ #2  [Mask] crack    @(620,480)  1290px│  ← 같은 클래스, 다른 위치
│ #3  [Mask] defect   @(330,310)  420px │
│ #1  [Poly] scratch  @(200,180)  8pts  │
└──────────────────────────────────────┘
```

- 각 항목: **`#순번 [타입] 클래스명 @(중심좌표) 면적`**
- 같은 클래스라도 **다른 위치의 블롭은 별개로 표시** (연결 컴포넌트 단위)
- 클릭 = 해당 어노테이션을 캔버스에서 하이라이트
- Ctrl/Shift 로 다중 선택 → Del 로 삭제 가능
- 선택 도구와 **양방향 동기화**: 캔버스 선택 ↔ 목록 선택

### 📝 우측 하단 — 로그 패널

```
┌─ 📝 로그 ──────────── [🧹] [📂] ┐
│ • 이미지 열기: frame_003.jpg   │

```

- 실행 기록·경고·오류 실시간 표시
- 레벨별 색상: 회색(INFO) · 노랑(WARN) · 빨강(ERROR)
- **🧹** — 목록 지우기
- **📂** — 로그 파일 폴더 열기
- 실제 파일: `data/logs/app.log` (전체) + `data/logs/errors.log` (WARN+만)

### ⚙️ 좌측 — 설정 폼
- **데이터**: image_w/h, val 비율, num_workers

- **옵티마이저**: Adam / AdamW / SGD / RMSprop · weight_decay · momentum

## 🩺 트러블슈팅

### ❌ `[WinError 1114] DLL 초기화 실패 — c10.dll`
**원인**: Microsoft Visual C++ Redistributable 미설치 (99% 의 경우).
**해결**:
1. https://aka.ms/vs/17/release/vc_redist.x64.exe 다운+설치+재부팅
2. 안 되면 venv 재생성 + pip 업그레이드 후 `--index-url` 로 CUDA 빌드 명시

### ❌ GPU 사용 불가 (CPU 만 작동)
**진단 (로그 `errors.log` 확인)**:
- `torch.version.cuda=None` → PyTorch 가 CPU 전용 빌드
- CUDA 초기화 오류 → NVIDIA 드라이버 문제

**해결**:
```powershell
# 현재 torch 확인
py -m pip show torch

# CUDA 빌드로 재설치 (GPU 맞는 cuXXX)
py -m pip install --upgrade torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

### ❌ 학습 중 CUDA OOM (메모리 부족)
앱이 구체적인 해결책 메시지를 띄움:
- Batch Size 절반으로 줄이기
- 이미지 크기 줄이기
- DataLoader Workers = 0
- `nvidia-smi` 로 GPU 점유 프로그램 확인
- Mixed Precision 끄기

### ⚠️ 구형 GPU (Maxwell - Quadro M4000/M5000, GTX 9xx)
- CC 5.2 → PyTorch CUDA 11.x 까지 안정
- AMP(Mixed Precision) 자동 비활성화
- `errors.log` 에 "Maxwell 세대 — AMP 자동 비활성화" 경고 찍힘
- 학습은 작동하지만 최신 GPU 대비 느림

### ⚠️ 매우 큰 이미지 (50MB+)
- 이미 브러시 bbox 최적화, 오버레이 QPixmap 캐싱 등으로 대응
- 그래도 느리면 학습 탭에서 이미지 크기를 768×768 이하로 줄여 학습
- 라벨링 시 필요하면 이미지 다운샘플링 후 작업하는 것도 방법

### ❌ Anaconda 와 venv 환경 혼동
**증상**: pip install 해도 앱에서 안 보임
**원인**: 앱이 Anaconda Python 에서 실행되는데 pip 은 venv 에 설치하는 경우
**해결**:
```powershell
# 앱이 쓰는 python 경로 확인
"C:\Users\<이름>\anaconda3\python.exe" -c "import sys; print(sys.executable)"

# 정확한 python 에 직접 설치
"C:\Users\<이름>\anaconda3\python.exe" -m pip install ...
```

### 📌 시나리오 1 — 결함 탐지 프로젝트 처음부터 끝까지
1. **🗂** 앱 실행 → **🎯 새 프로젝트** "용접결함" 생성
2. **🎨 라벨링 탭**
   - 클래스 패널에서 `crack`, `porosity` 등 추가
   - **폴더** 버튼으로 이미지 일괄 추가 (100장)
   - 대표적인 결함 10~20장에 수동 라벨링 (🖌 브러시 + 📐 폴리곤 혼합)
3. **✨ 오토 라벨링** → 🚀 **빠른 학습 탭**
   - 모델: `U-Net` 선택 → **▶ 시작**
   - 30 epochs 학습 후 자동으로 미라벨 이미지 라벨링 진행
   - 미리보기에서 품질 확인 → **✅ 합치기**
4. **🎨 라벨링 탭** 다시
   - 자동 생성된 라벨 중 잘못된 것 수정 (🧹 지우개, 🔲 선택 + 클래스 변경)
   - `N` 키로 이전 이미지 복사해 비슷한 프레임 빠르게 처리
5. **🎯 학습 탭** — 본격 학습
   - 학습1: U-Net, 100 epochs
   - 학습2: Attention U-Net, 100 epochs
   - 학습3: DeepLabV3+MobileNet, 100 epochs
   - **▶ 모두 실행** → 세 모델 성능 비교
6. **🔍 추론 탭** — 최고 성능 모델로 신규 이미지 검증
7. **📤 내보내기** — YOLO-seg 포맷으로 다른 파이프라인에 연동
