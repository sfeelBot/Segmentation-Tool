1. 이 프로그램은 무엇을 하나요 ▲ 목차

배터리 캡 사진을 AI로 검사해서 캡 표면의 녹(변색) 부위가 어디에, 얼마나 있는지를 숫자로 뽑아 주는 프로그램입니다.

캡은 동그란 부품이라 중심에서 바깥으로 여러 겹의 원(테두리)이 있습니다. 이 프로그램은 그 원들을 기준으로 캡을 존(Zone)으로 나눈 뒤, 존마다 “녹이 몇 %인가”를 계산해 Excel로 저장합니다.

전체 흐름  →  ① 프로젝트 만들기 → ② 모델(AI 구조) 고르기 → ③ 녹 부위 라벨링 → ④ 학습 → ⑤ 추론으로 확인 → ⑥ 존 분석으로 존별 % 뽑기 → ⑦ Excel 저장
이미 학습된 체크포인트(.pt 파일)를 받았다면 ②③④는 건너뛰고 존 분석 탭부터 바로 사용하면 됩니다. 존 분석 탭은 프로젝트와 상관없이 이미지 파일과 체크포인트 파일을 직접 열어서 동작합니다.

2. 프로그램 시작하기 (프로젝트 선택) ▲ 목차

프로그램을 실행하면 가장 먼저 프로젝트 선택 창이 뜹니다. 프로젝트는 “이미지 + 라벨 + 학습 결과”를 한 폴더에 모아 두는 작업 단위입니다.

  1. ① 새 프로젝트 — 이름을 입력하면 projects/이름/ 폴더가 만들어집니다. 처음이라면 이걸 누르세요.
  2. ② 프로젝트 열기 — 이미 만들어 둔 프로젝트 폴더를 골라서 엽니다.
  3. ③ 프로젝트 가져오기 — 다른 PC에서 백업한 zip 파일을 풀어서 가져옵니다.
  4. ④ 최근 프로젝트 — 최근에 연 프로젝트 목록입니다. 더블클릭하면 바로 열립니다.

3. 화면 구성 한눈에 보기 ▲ 목차

  1. ① 라벨링 — 사진 위에 “여기가 녹이다”라고 색칠하는 탭입니다.
  2. ② 학습 — 라벨링한 자료로 AI를 학습시키는 탭입니다.
  3. ③ 추론 — 학습한 AI로 새 사진을 검사해 보는 탭입니다.
  4. ④ 모델 — AI 구조(설계도)를 고르거나 붙여 넣는 탭입니다.
  5. ⑤ 존 분석 — 이 에디션의 핵심 탭. 캡을 존으로 나눠 녹 비율을 계산합니다.
  6. ⑥ 현재 열려 있는 프로젝트 이름입니다.
  7. ⑦ 프로젝트 전환 — 프로그램을 끄지 않고 다른 프로젝트로 바꿉니다.
  8. ⑧ 설정 — 언어, 단축키 목록, 로그 파일 위치를 볼 수 있습니다.

맨 아래 상태바에는 현재 프로젝트 이름과 폴더 경로가 계속 표시됩니다.

4. 모델 탭 — AI 구조 고르기 ▲ 목차

AI의 “설계도”를 고르는 탭입니다. 직접 코드를 쓸 줄 몰라도 됩니다 — 프리셋(미리 준비된 모델) 중에서 하나 고르면 됩니다.

  1. ① AI 모델 프리셋… — 준비된 모델 목록을 엽니다. (아래 그림)
  2. ② 코드 편집 창 — 프리셋을 고르면 여기에 코드가 채워집니다.
  3. ③ 검증(Validate) — 코드에 문제가 없는지 검사합니다.
  4. ④ 로드(Load Model) — 검증을 통과하면 눌러서 모델을 준비합니다.
  5. ⑤ 현재 상태 표시 — 통과하면 초록색으로 모델 이름이 나옵니다.
처음이라면 U-Net (2015)을 고르면 됩니다. 자료가 적어도 잘 동작하는 기본 모델입니다.
  1. ① 진행 기록 — 검증 통과 ✓, 로드 완료 ✓ 가 보이면 성공입니다.
  2. ② 오른쪽 아래에 모델 이름과 파라미터 수가 초록색으로 표시됩니다.

5. 라벨링 탭 — 녹 부위 표시하기 ▲ 목차

AI에게 “이게 녹이다”라고 알려 주는 작업입니다. 사진 몇 장에만 표시해 주면 됩니다.

  1. ① 이미지 목록 — 파일/폴더 버튼으로 사진을 추가합니다. 초록 점은 라벨링이 끝난 사진입니다.
  2. ② 클래스 목록 — 색칠할 종류입니다. 여기서는 녹을 고른 상태입니다. + 버튼으로 추가할 수 있습니다.
  3. ③ 캔버스 — 실제로 색칠하는 곳입니다. 빨간 부분이 “녹”으로 표시한 영역입니다.
  4. ④ 어노테이션 목록 — 이 사진에 표시한 영역들의 목록입니다.
  5. ⑤ 로그 — 저장 여부 등 진행 상황이 표시됩니다.

도구 모음

  1. ① 폴리곤(단축키 P) — 점을 찍어 다각형을 그립니다. 더블클릭하면 닫힙니다.
  2. ② 브러시(B) — 붓처럼 끌어서 칠합니다.
  3. ③ 윤곽 채우기(F) — 테두리만 그리면 안쪽이 자동으로 채워집니다.
  4. ④ 지우개(E) — 끌어서 칠한 것을 지웁니다.
  5. ⑤ 연결 지우개 — 클릭 한 번으로 이어져 있는 영역을 통째로 지웁니다.
  6. ⑥ 선택(S) — 이미 그린 영역을 고르고 옮기거나 클래스를 바꿉니다.
  7. ⑦ 화면 이동(H) — 그림을 끌어서 옮깁니다. (마우스 휠 = 확대/축소)
  8. ⑧ 브러시 크기 — 붓 굵기입니다. [ ] 키로도 조절됩니다.
저장 버튼은 따로 없습니다. 그리면 자동으로 저장됩니다. 실수했으면 Ctrl+Z로 되돌리세요.

6. 학습 탭 — AI 학습시키기 ▲ 목차

  1. ① 설정 폼 — 학습 조건입니다. 잘 모르겠으면 기본값 그대로 두세요. 자주 바꾸는 항목은 아래 표를 보세요.

7. 추론 탭 — 학습한 AI로 검사하기 ▲ 목차

존 분석에 들어가기 전에, AI가 녹을 제대로 찾는지 눈으로 먼저 확인하는 탭입니다.

  1. ① 파일 선택… — 사진을 한 장 또는 여러 장 고릅니다.
  2. ② 폴더 선택… — 폴더 안 사진을 모두 불러옵니다.
  3. ③ 체크포인트 목록 — 학습 결과 중 쓸 것을 한 줄 클릭해서 고릅니다.
  4. ④ 추론 방식 — resize는 사진을 줄여서 한 번에, sliding window는 원래 크기로 잘라가며 검사합니다.
  5. ⑤ 추론 실행 — 검사를 시작합니다.
학습할 때 random_crop(패치 학습)을 썼다면 추론도 sliding window를 고르는 것이 정확합니다.
  1. ① 이미지 목록 — 클릭해서 사진을 바꿔 봅니다.
  2. ② 결과 화면 — 아래 슬라이더로 색이 얼마나 진하게 덮일지 조절합니다. F 키로 원본/결과 전환.
  3. ③ 클래스 범례 — 클래스별로 몇 %가 검출됐는지 나옵니다.
  4. ④ Excel로 내보내기 — 검출 결과를 표로 저장합니다.

8. 존 분석 탭 — 이 도구의 핵심 ▲ 목차

8.1 존 분석이란

캡을 동심원으로 잘라 만든 구역이 존(Zone)입니다. 원을 반지름이 작은 것부터 정렬해서 다음과 같이 이름이 붙습니다.

존 이름어디를 말하나
중심부가장 작은 원의 안쪽
링 1, 링 2, …원과 원 사이의 고리 모양 구역 (안쪽부터 번호)
바깥쪽가장 큰 원의 바깥 (배경 포함)

원을 N개 그리면 존은 N+1개가 생기고, 각 존마다 “타겟(녹) 픽셀 비율 %”이 계산됩니다.

존 분석 탭은 다른 4개 탭과 완전히 따로 동작합니다. 프로젝트에 이미지를 등록할 필요가 없고, 아무 폴더의 사진과 아무 위치의 체크포인트 파일을 직접 열어서 씁니다.

8.2 1단계 · 검사할 이미지 열기

  1. ① 이미지 열기… — 사진 파일을 직접 고릅니다(여러 장 선택 가능).
  2. ② 폴더 열기… — 폴더를 통째로 엽니다. 하위 폴더까지 찾아 줍니다.
  3. ③ 이미지 목록 — 사진이 2장 이상일 때 나타납니다. 클릭하면 그 사진으로 바뀝니다.
  4. ④ 체크포인트 열기 (.pt)… — 다음 단계에서 누릅니다.
  5. ⑤ 캔버스 — 사진이 보이는 곳. 휠로 확대/축소합니다.

8.3 2단계 · 체크포인트(학습 결과) 열기

  1. ① 체크포인트 열기 (.pt)… — 학습 결과 파일을 고릅니다.
  2. ② 고른 파일 이름이 표시됩니다.
  3. ③ 모델 정보 — 초록색으로 (자동 준비됨)이 나오면 바로 쓸 수 있습니다.
  4. ④ 추론 방식 — 기본값은 sliding window입니다.
  5. ⑤ 추론 실행 — 다음 단계.
노란색/빨간색 안내가 뜬 경우: 프리셋이 아닌 직접 만든 모델로 학습한 체크포인트입니다. 화면 아래에 코드 입력 상자가 나타나므로, 그 모델의 코드를 붙여 넣고 검증(Validate) → 로드(Load Model)를 차례로 누르세요.

8.4 3단계 · 추론 실행

▶ 추론 실행을 누르면 목록에 있는 사진 전부를 AI가 검사합니다. 끝나면 사진 위에 녹으로 판단한 부위가 색으로 덮여 표시됩니다.

  1. ① 추론 실행 버튼.
  2. ② 진행 상황 (완료 5 / 5처럼 표시).
  3. ③ 타겟(녹) 클래스 — 아래 8.5 설명 참고.
  4. ④ 검출된 클래스 개수 안내 문구.
  5. ⑤ 결과가 덮여 표시된 캔버스. F 키를 누르면 원본과 번갈아 볼 수 있습니다.

8.5 4단계 · 타겟(녹) 클래스와 민감도 정하기

AI가 여러 종류를 찾도록 학습됐다면 그중 어느 것을 “녹”으로 볼지 골라야 합니다.

  • 검출된 종류가 1개면 이름 입력칸이 나옵니다 — 원하는 이름(예: 녹)으로 바꿔도 됩니다.
  • 검출된 종류가 2개 이상이면 드롭다운이 나옵니다 — 녹에 해당하는 항목을 고르세요.
  1. ① AI 신뢰도 — 이 값보다 자신 없는 덩어리는 버립니다. 잡티가 많으면 올리세요.
  2. ② 픽셀 threshold — 이 크기(픽셀 수)보다 작은 덩어리는 버립니다. 작은 점 노이즈 제거용.
  3. ③ 민감도 — 아래 자동 검출이 원을 얼마나 적극적으로 찾을지 정합니다(원 검출 전용, AI와 무관).
  4. ④ 자동 검출 — 캡의 동심원을 자동으로 찾습니다.
①②를 바꾸면 화면과 존별 % 가 즉시 다시 계산됩니다. 값을 조금씩 움직이며 결과를 보면 됩니다.

8.6 5단계 · 원(존 경계) 만들기

자동 검출 버튼을 누르면 캡의 동심원을 찾아 초록색 원으로 그려 줍니다.

  1. ① 민감도 — 원이 안 잡히면 올리고, 엉뚱한 원이 잡히면 내린 뒤 다시 누르세요.
  2. ② 자동 검출 버튼.
  3. ③ 검출된 원 목록 — 반지름이 작은 것부터 정렬됩니다. 클릭하면 캔버스에서 노란색으로 강조됩니다.
  4. ④ 존별 타겟 클래스 비율(%) — 원이 정해지면 자동으로 계산됩니다.
  5. ⑤ 캔버스에 그려진 원.
자동 검출이 원을 하나도 못 찾으면 안내창이 뜹니다. 그럴 땐 민감도를 조절하거나 직접 그리면 됩니다(다음 절).

8.7 6단계 · 원 수동으로 고치기

원 편집 도구가 켜져 있을 때(도구 모음 첫 번째 아이콘) 다음 조작을 할 수 있습니다.

  1. ① 원 목록에서 클릭 — 캔버스의 해당 원이 선택됩니다(반대로 캔버스에서 고르면 목록이 따라옵니다).
  2. ② 원의 중심점 — 여기를 끌면 원이 이동합니다.
  3. ③ 원의 테두리 — 여기를 끌면 크기(반지름)가 바뀝니다.
하고 싶은 것조작
새 원 그리기빈 곳에서 바깥쪽으로 드래그. (이미 원이 있으면 중심은 기존 원들의 평균 중심으로 자동 맞춤)
원 옮기기원의 중심점을 드래그
크기 바꾸기원의 테두리를 드래그
정확한 숫자로 크기 지정원 위에서 우클릭 → 지름 변경…
원 지우기원 위에서 우클릭 → 원 삭제, 또는 선택 후 Delete

8.8 7단계 · 존별 비율 확인하기

  1. ① 존 목록 — 링 1 — 16.16% 처럼 존 이름과 녹 비율이 나옵니다.
  2. ② 선택한 존이 캔버스에서 노란색으로 강조됩니다. 반대로 캔버스의 빈 곳을 클릭해도 그 위치의 존이 선택됩니다.
  3. ③ Excel로 내보내기 — 지금 화면의 존 목록(사진 1장)을 xlsx로 저장합니다.

8.9 8단계 · 편집 도구 5종

AI 결과가 완벽하진 않습니다. 잘못 잡힌 곳을 지우거나 빠진 곳을 채우는 도구가 있습니다. 다섯 개 중 항상 하나만 켜집니다.

  1. ① 원 편집 — 원을 만들고 옮기고 크기를 바꿉니다(기본 상태).
  2. ② 브러시로 타겟 영역 그리기 — AI가 놓친 녹을 직접 칠해서 넣습니다(초록색).
  3. ③ 브러시로 타겟 영역 지우기 — 잘못 잡힌 부분을 문질러 지웁니다(빨간색).
  4. ④ 클릭한 연결 블랍 삭제 — 이어져 있는 덩어리 하나를 클릭 한 번으로 통째로 뺍니다.
  5. ⑤ 화면 이동 — 그림을 끌어서 옮깁니다.
  6. ⑥ 브러시 크기 — ②③에서 쓰는 붓 굵기(원본 사진 픽셀 기준).
  7. ⑦ 실행 취소 — 원 편집·그리기·지우기·블랍 삭제를 시간 순서대로 되돌립니다(Ctrl+Z).

브러시로 그리기

  1. ① 브러시 그리기 도구를 켭니다.
  2. ② 브러시 크기를 정합니다.
  3. ③ 캔버스에서 드래그하면 초록색으로 칠해집니다.
  4. ④ 손을 떼는 순간 존별 비율이 다시 계산됩니다.

브러시로 지우기

  1. ① 브러시 지우기 도구를 켭니다.
  2. ② 지울 곳을 드래그합니다.
  3. ③ 잘못 지웠으면 실행 취소(Ctrl+Z).

블랍(덩어리) 삭제

  1. ① 블랍 삭제 도구를 켭니다.
  2. ② 없앨 덩어리를 클릭합니다.
  3. ③ 현재 존별 비율.
  1. ① 삭제된 덩어리는 붉은 사각형으로 표시됩니다.
  2. ② 존별 비율이 그만큼 줄어든 것을 확인하세요.
  3. ③ 되돌리려면 실행 취소.

8.10 9단계 · 이미지별 자동 저장

존 분석 탭에서 한 작업(원 위치, 지운 덩어리, 브러시 자국)은 사진마다 자동으로 저장됩니다. 저장 위치는 사진 파일 바로 옆의 사진이름.zone.json 파일입니다. 다른 사진을 봤다가 돌아오면 하던 작업이 그대로 복원됩니다. 따로 저장 버튼을 누를 필요가 없습니다.

단, 사진의 원본 자체는 건드리지 않습니다. 편집 내용을 완전히 지우고 싶으면 해당 .zone.json 파일을 지우면 됩니다.

8.11 10단계 · Zone 결정 방법 3가지와 일괄 처리

사진이 여러 장일 때, 원을 어떻게 정할지를 고르는 곳입니다.

모드어떻게 동작하나언제 쓰나
일괄 적용 지금 화면(기준 사진)의 원을 나머지 사진 전부에 그대로 적용합니다(사진 크기가 다르면 비율에 맞춰 조정). 같은 위치·같은 카메라로 찍어 캡 위치가 일정할 때 — 가장 빠릅니다.
일괄 적용 후 수정 위와 같이 적용한 뒤, 사진을 하나씩 열어 원을 직접 손볼 수 있습니다(수정 내용은 자동 저장). 대체로 위치는 같지만 몇 장은 틀어져 있을 때.
장별 적용(이미지별 개별) 사진마다 따로 자동 검출을 돌립니다(민감도 슬라이더 값 사용). 사진마다 캡 위치·크기가 제각각일 때.
  1. ① Zone 결정 방법 — 위 표에서 고릅니다.
  2. ② 선택 이미지 일괄 처리 (N장) — 누르면 처리가 시작됩니다. 괄호 안 숫자가 대상 장수입니다.
  3. ③ 필요 조건 안내 — 추론 실행 + 원 1개 이상 + 이미지 2장 이상이어야 버튼이 켜집니다.
  4. ④ 이미지 목록 — Ctrl/Shift로 일부만 골라 처리할 수도 있습니다.
이미지 목록에서 딱 1장만 고른 경우에는 목록 전체가 처리됩니다. 한 장만 확인하고 싶으면 그 사진을 클릭해 캔버스에서 직접 보세요.
  • 기존 존을 대체하고 전체 적용 — 저장돼 있던 원을 새 기준으로 덮어씁니다.
  • 존 없는 이미지만 적용 — 이미 작업한 사진은 그대로 두고 나머지만 처리합니다.
  • 취소 — 아무것도 하지 않습니다.
처리 중 화면 — 시작하면 3 / 12 사진이름.png 처럼 진행 상황을 보여 주는 작은 창이 뜹니다. 취소를 누르면 중간에 멈출 수 있고, 그때까지 처리된 결과는 그대로 표로 나옵니다. 왼쪽 이미지 목록에도 사진마다 처리 상태와 마지막 존의 비율이 표시됩니다. 이미 추론이 끝난 사진은 결과를 다시 쓰기 때문에 몇 장이면 순식간에 끝납니다.

8.12 11단계 · Excel로 내보내기

  1. ① 목록별(Long) 탭 — 한 줄에 (이미지, 존, 비율%) 하나씩. 이게 원본 데이터입니다.
  2. ② 이미지별(Wide) 탭 — 사진을 한 줄로, 존을 열로 펼친 표입니다.
  3. ③ Excel로 내보내기 — xlsx 파일로 저장합니다.
내보내기 버튼이 두 군데 있습니다.
· 화면 오른쪽 아래 Excel로 내보내기(8.8 ③) — 지금 보고 있는 사진 1장만 저장
· 일괄 처리 결과 창의 Excel로 내보내기(위 ③) — 처리한 모든 사진 저장
저장 형식은 둘 다 같습니다 — 이미지 / 존 / 타겟 비율(%) 세 개 열.

10. 문제가 생겼을 때 ▲ 목차

“배경 외 클래스가 검출되지 않았습니다”라고 나옵니다

AI가 녹을 하나도 못 찾았다는 뜻입니다. ① 체크포인트를 다른 것으로 바꿔 보고, ② 추론 방식을 sliding window로 바꿔 보고, ③ 그래도 안 되면 라벨링을 더 해서 다시 학습하세요.

일괄 처리 버튼이 회색이라 눌리지 않습니다

세 가지 조건이 모두 필요합니다 — 추론을 실행했고, 원이 1개 이상 있고, 이미지가 2장 이상. 왼쪽 아래 안내 문구에 같은 내용이 적혀 있습니다.

원이 이상하게 잡힙니다

민감도를 낮춰서(잡음 감소) 또는 높여서(더 많이 검출) 다시 자동 검출을 누르세요. 그래도 안 되면 원을 지우고 직접 드래그해서 그린 뒤, 우클릭 지름 변경…으로 숫자를 맞추면 정확합니다.

편집한 내용이 사라졌습니다

사진 옆 사진이름.zone.json 파일이 지워졌거나, 폴더가 읽기 전용이라 저장에 실패한 경우입니다. 저장에 실패하면 한 번은 경고창이 뜹니다. USB나 네트워크 드라이브가 아닌 PC 내부 폴더에서 작업하세요.

학습 중 메모리 부족(CUDA out of memory) 오류

학습 탭에서 Batch Size를 절반으로 줄이거나, 이미지 크기(IMG SIZE)를 줄이세요. Mixed Precision을 꺼 보는 것도 방법입니다.

그 밖의 오류

오른쪽 위 설정 → 로그에서 로그 파일 위치를 확인할 수 있습니다. 문제가 계속되면 data/logs/errors.log 파일을 담당자에게 전달하세요.
