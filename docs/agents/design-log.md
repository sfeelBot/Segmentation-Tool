### 무엇을 목업했나 (Before/After 비교, 3탭 + 확대 비교 1개)
- **라벨링 탭**: 좌 패널(이미지브라우저↔클래스패널) · 우 패널(어노테이션목록↔로그패널)에
  세로 QSplitter 추가 — 초기 비율 3:2 / 2:3 유지, 드래그 그립(파란 hover 바)으로 표현.
  `ClassPanel` 200px 상한 제거 후 클래스 8개가 스크롤 없이 보이는 상태를 After에 반영.
- **학습 탭**: 큐 박스(작업추가+큐리스트+제어버튼) ↔ 진행상태/그래프/메트릭 영역 사이
  세로 QSplitter 추가. `_queue_list` maxHeight(140) 제거 후 큐 4개가 스크롤 없이 보이는
  상태를 After에 반영. 좌측 설정폼·그래프|사이드패널 가로분할은 변경 없음을 명시.
- **추론 탭**: 상단(파일컨트롤+추론방식+체크포인트테이블) ↔ 메인뷰어(목록|뷰어|범례) 영역
  사이 세로 QSplitter 추가, 테이블 maxHeight(120) 제거.
- **추론 탭 이미지 목록 신규 컴포넌트**: 64px 썸네일 아이콘 그리드 → 검색창+정렬콤보(파일명↑/
  파일명↓/폴더)+폴더 트리(라벨링 탭 `ImageBrowser`와 동일한 폴더헤더 `#60a5fa`/`#1a2235`,
  상태기호 스타일) 구조로 교체. 별도 "확대 비교" 섹션에서 64px 그리드 vs 트리 행을 실제 크기
  감각으로 나란히 배치해 트레이드오프(큰 프리뷰 상실)를 명확히 시각화.

### 색상·레이아웃 일관성 확인
`main.py` 전역 스타일시트 값을 그대로 사용 — 배경 `#1a1d23`(기본)/`#1f2329`(그룹박스·툴바)/
`#111418`(입력창·리스트), 테두리 `#374151`(기본)/`#4b5563`(강조), 강조색 `#60a5fa`, 성공
`#10b981`/`#34d399`, 경고 `#fbbf24`, 오류 `#f87171`. `QSplitter::handle:hover` 파란 강조는
기존 라벨링/학습/추론 메인 스플리터와 동일 패턴(회색→호버시 `#60a5fa`)으로 신규 서브
스플리터에도 통일 적용. `image_browser.py`의 트리 스타일(폴더헤더 `#1a2235`/`#60a5fa`,
상태기호 `●`/`✓`/`○` 색상 `#6ddf6d`/`#5ba8ff`/`#999999`)을 추론 탭 신규 컴포넌트 목업에
그대로 재사용해 시각적 통일성 확보. 단축키는 이번 라운드가 레이아웃 구조 변경만 다루므로
영향 없음(변경 없음 확인).

### 구현 시 참고 — 주의사항
- **QTreeWidgetItem 구조 제안**: `image_browser.py`의 `_make_tree_item`/`_make_folder_item`
  패턴을 그대로 참고하되, 추론 탭은 라벨 상태 개념이 없으므로 상태기호(`●`/`✓`/`○`) 대신
  UserRole에 Path만 저장하고 텍스트는 파일명만 표시. 목업에서는 절충안으로 행 왼쪽에
  18~24px 미니 썸네일(`QIcon`/`QPixmap` 스케일)을 얹는 것을 제안했음 — 스펙 문서가 이미
  "가능한 절충"으로 언급한 내용이라 구현 재량으로 반영 여부 결정 가능(사용자 재확인 불필요).
- **세로 QSplitter 초기 비율**: `setSizes()`로 기존 stretch 비율(3:2, 2:3 등)과 동일한
  픽셀 비율을 지정할 것 — 목업은 이 "초기 상태는 기존과 동일, 이후 자유 조정"을 전제로
  그렸으므로 구현이 초기 비율을 다르게 잡으면 목업과 어긋난다.
- **`ClassPanel`/`_queue_list`/체크포인트테이블 상한 제거**는 상위 컨테이너가 QSplitter로
  바뀐 뒤에만 의미가 있다(사용자가 이미 확인한 전제) — 상한만 먼저 제거하고 스플리터 전환이
  누락되면 레이아웃이 무너질 수 있으니 두 변경을 같은 커밋/같은 검증 라운드에서 함께 처리할 것.
- 라운드 3(정보 추가) 대상은 이번 목업 범위 밖 — 신뢰도 컬럼, LR 표시, 줌/이미지크기 표시 등은
  별도 목업 필요.
