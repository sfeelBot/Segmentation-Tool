## 결정 대기

- **GitHub #5 "모델 탭 변경" 진행 여부** — 독립 탭이던 모델 탭을 폐지하고, 학습 탭의 모델
  선택 영역에 "+" 버튼을 추가해 누르면 모델 탭 내용을 모달/팝업으로 띄우는 구조로 바꿔달라는
  요청. `win._model_tab.loaded_model`을 학습 탭뿐 아니라 라벨링 탭(오토라벨링)·추론 탭
  (커스텀 모델 재구성)도 참조하고 있어 파급 범위가 3개 탭에 걸침 — 인스턴스 유지 등 구현
  방식은 스펙에 정리했으나, **탭 기반 UI 패러다임을 부분적으로 깨는 구조 변경 자체를 진행할지,
  진행한다면 라벨링 탭에도 같은 진입점을 둘지**는 리더가 사용자에게 확인 필요. 상세:
  [docs/specs/voc-github-issues-round2-2026-08-20.md](specs/voc-github-issues-round2-2026-08-20.md)
  "#5" 절.
- **GitHub #3 "브러시 크기 조절" 인터랙션 방식** — 더블클릭 시 정확히 어떤 동작(팝업 슬라이더?
  프리셋 크기 순환?)을 할지, 그리고 우클릭 방식은 기존 "우클릭=패닝" 전역 배정과 충돌하므로
  포기할지 또는 modifier 조합(예: Alt+우클릭 드래그)으로 변형해서라도 유지할지 확인 필요.
  잘림 버그(#3 부속)와 이미지명 복사(#4)·OK 확인팝업(#7)·어노테이션 개수비례 지연(#6-B)·
  flicker(#6-A)는 방향이 명확해 결정 없이 바로 구현 가능. 상세:
  [docs/specs/voc-github-issues-round2-2026-08-20.md](specs/voc-github-issues-round2-2026-08-20.md)
  "#3" 절.

- **BUG-005(P2) 처리 방향** — 라벨링/추론 탭 이미지 브라우저의 "폴더 그룹핑" 기능이
  실제로는 어떤 사용자 동작으로도 트리거되지 않는 죽은 코드로 확인됨(`reload()`가
  비재귀 스캔만 하고, 이미지 추가 경로도 전부 평탄 복사). GitHub #1에서 "라벨링 탭은
  기존부터 폴더 트리 있음"이라 답했던 것도 실제로는 도달 불가능한 기능이었음 — 사용자에게
  재정정 필요. 상세: `QA.md` BUG-005, [docs/agents/verification-log.md](agents/verification-log.md)
  "장식 이모지 제거 라운드 검증" 항목. 선택지:
  1. 지금 별도 라운드로 고친다 — `_on_add_folder()`가 원본 하위구조 보존해 복사 +
     `reload()` 재귀 스캔 전환(단 `dataset.py` 학습 스캔 로직과 동치성 맞춰야 함, 2026-05-27
     `00fd6779`가 의도적으로 비재귀로 만든 이유이므로 함께 검토 필요).
  2. 현재 진행 중인 "디자인 톤 홀리스틱 재검토" 7단계 실행(학습/추론 탭 재편 등) 끝난 뒤로
     미룬다.
  3. 추론 탭에 이번에 신규 구현될 트리형 폴더 그룹핑(라운드 2 목업, 실행안 5단계)과 함께
     한 번에 고친다 — 라벨링 탭도 같은 근본 원인이라 묶어서 처리하면 중복 작업 방지.
